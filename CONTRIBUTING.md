# Pull requests

- If the modification you have made is to the main branch in order to fix an issue/error/bug, then
  have it set to master
- Else if the modification is for a new experimental feature, push to development.
- If you want to have your website/icon appear in the credits section, please add it
  to [Contributors.kt](buildSrc/src/main/kotlin/Contributors.kt) and include that change in your
  pull request.
